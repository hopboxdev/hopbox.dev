Your dev environments,

A self-hosted control plane for development environments. Persistent, reproducible workspaces on Docker or Kubernetes — reachable from anywhere, even behind NAT or a private cluster.

curl -fsSL https://hopbox.dev/install.sh | sudo sh 
# spin up a workspace$ hopbox create demo --image ubuntu:24.04 --expose app:8000created demo (a1b2c3) phase=Running$ hopbox exec demo -- uname -aLinux a1b2c3 6.12 x86_64 GNU/Linux$ open https://app-a1b2c3.gw.yourdomain

Reverse-dialing agent

Each workspace dials out and holds one multiplexed connection — the control plane never needs a route in.

⧉

Swappable providers

Compute, storage, ingress, identity, build, metering — six versioned contracts. Docker, Kubernetes, your brick.

∞

Unlimited endpoints

Host-routed HTTPS with one wildcard cert gives every workspace its own URL — no port allocation.

⟳

Declarative core

A reconciler drives each workspace to its spec and heals drift. The same engine, laptop to platform.
