SHIPPED IN v0.1.0

A real computer, one command away. Yours to keep.

A microVM per machine

Each machine is a Firecracker microVM in a jail, with its own kernel. It keeps running through a restart or an upgrade of the server.

Reach it your way

ssh box1.hop, scp, sftp, rsync, and port forwards. Or hopbox connect and the web terminal, with no SSH key.

An HTTPS URL each

Every machine gets its own URL. It is private until you flip it public, and you pick the port it reaches.

Built for agents

An MCP server turns the API into tools. Your agent creates machines, runs commands, and moves files, with the rights of its key and no more.

CLI, API, and SDK

A typed API with idempotency keys, a TypeScript SDK, and a CLI with tab completion and JSON output for scripts.

Made for teams

Orgs with owners, admins, and members. API keys, env vars, sealed secrets, shared machines, and an audit log.

FOR AI AGENTS

Give your agent a computer, not a sandbox snippet.

Point any MCP client at hopbox. The agent gets tools to create machines, run commands, read and write files, read logs, and publish URLs.

It acts with the rights of the key you give it. It cannot make keys, invite people, or delete your account.
